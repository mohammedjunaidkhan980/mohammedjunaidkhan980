### What I do now — Data Engineering on GCP

I design and build data pipelines on Google Cloud Platform. From raw ingestion to clean,
tested, reporting-ready data — I own the full pipeline.

**GCP DBT Finance Pipeline** — Built an end-to-end ELT pipeline on GCP. Raw finance
transaction data lands in Google Cloud Storage, gets loaded into BigQuery, and flows
through three dbt layers — staging, intermediate, and marts. Data quality tests run
automatically on every model. Final table connects directly to Looker Studio.

The stack: **GCS → BigQuery → dbt → Looker Studio**

What I bring to data engineering:
- **ETL & ELT** — design, build, and optimize both patterns depending on the use case
- **Apache Airflow** — building and scheduling DAGs for complex pipeline orchestration
- **PySpark** — distributed data processing for large-scale datasets
- **dbt** — data modeling, testing, and documentation inside BigQuery
- **Advanced SQL** — window functions, CTEs, query optimization, partitioning, clustering
- **Pub/Sub + Dataflow** — real-time streaming pipelines on GCP
- **Cloud Composer** — managed Airflow on GCP for production DAG scheduling
